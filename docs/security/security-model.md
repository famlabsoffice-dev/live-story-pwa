# Security Model

## Protection Layers

1. Identity protection
2. Encrypted local storage
3. Media integrity verification
4. Consent enforcement
5. AI privacy controls

## Threat Protection

Protected against:

- Unauthorized data access
- Media manipulation
- Accidental AI data leakage
- Missing consent flows

## Local Security Boundary

Sensitive life story data remains inside the application storage boundary unless the user explicitly allows external processing.
