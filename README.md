# Live Story PWA

Dies ist eine Next.js Progressive Web App (PWA).

## Struktur

- `src/app`: App Router Seiten und Layouts
- `src/components`: Wiederverwendbare React-Komponenten
- `src/lib`: Hilfsfunktionen und Bibliothekskonfigurationen
- `src/hooks`: Custom React Hooks
- `src/types`: TypeScript Typdefinitionen
- `src/config`: Anwendungskonfiguration

## Entwicklung

```bash
npm install
npm run dev
```
